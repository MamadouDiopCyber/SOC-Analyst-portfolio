# HIPAA Security Rule Gap Review
## Project Overview

This is a fictional junior GRC portfolio project created to practice
mapping security controls to selected HIPAA Security Rule requirements.

I reviewed the information supplied in the PulseTrack Health scenario, then I 
assigned preliminary control statuses, identified possible gaps, and
listed the evidence that an analyst would request before determining
whether each control operates effectively.

## Scope

The review covers a selection of administrative, physical, and technical
safeguards, including:

- Security risk analysis
- Employee termination procedures
- Security-awareness training
- Business associate agreements
- Device and media controls
- Access control
- Audit logging

## Work Performed

For each selected requirement, I:

- Reviewed the control described in the fictional scenario
- Mapped it to a HIPAA Security Rule reference
- Assigned a preliminary status
- Identified evidence that would be requested
- Proposed a reasonable next step for an identified gap

## Preliminary Findings

I identified several areas requiring additional evidence and
follow-up. Examples : confirming employee offboarding timestamps,
reviewing training-completion records, verifying business associate
agreements, and confirming laptop encryption

The statuses in this project are preliminary because no real system
access, interviews, configuration exports, or company records were
available.

## Skills Practiced

- Control mapping
- Gap identification
- Evidence-request planning
- Compliance documentation
- Remediation tracking
- HIPAA Security Rule research

## Project Disclosure

This is an educational portfolio project based on a fictional
organization I created. It does not represent a professional audit, or assessment
performed for an actual healthcare organization.

No real patient information, company records, credentials, or
confidential data are included.
